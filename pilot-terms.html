Early Access Scope

Last updated: November 12, 2026. This page describes the proposed trial process; it is not an automatically effective license or a promise of access.

What is available?

Anyone can view the static fictional preview and actual engine-generated fictional HTML report. A limited, manually approved 14-day no-charge pilot may provide an unsigned Windows portable EXE or a Python 3.10+ zipapp. Only approved local recordings should be analyzed, and raw logs must not be posted in public issues.

What does the tool do?

RIA presents candidate anomalies, evidence links and offline HTML/JSON reports for human engineering investigation. It is not a fleet monitoring service, robot control component, safety system, verified root-cause diagnostician or certified product. There is no promise of uninterrupted operation or field-fault accuracy.

How is it delivered?

Pilot approval and binary-only delivery are manual. You should verify the release version and SHA-256 before executing. We do not grant access to private source code as a default part of an artifact-only trial. A separate secure delivery path and written evaluation terms must be agreed before the owner sends any binary. The public site does not offer an instant executable download.

Commercial use

Team onboarding, paid pilots and future licenses are discussed individually. No price, paid order, production SLA, support obligation or commercial license is created through a public GitHub issue. Formal terms, invoicing and the handling of confidential data require a separate agreement.

Never use RIA findings as the sole basis for operating, stopping or protecting a robot. Use independent safety mechanisms and human validation.
