Prepare your evaluation request.

Four answers are enough for a first review. You can build and copy the request here without an account. It is submitted only when you post it in the public GitHub form — this page has no server, sends nothing, and stores nothing on your device.

Why a GitHub step? The only verified submission channel today is a public GitHub issue, so a GitHub account is required at that last step. Until a private channel is verified, this site never claims that your request was received.

What happens next

  1. You post the public issue. GitHub prefills the three dropdown answers from your draft. Paste the goal sentence into “What is the main problem you want to solve?” if it is not carried over.
  2. Manual review. A request does not guarantee approval or immediate access, and there is no automatic activation.
  3. Private delivery is arranged separately. Approved evaluators agree a secure binary-only channel and the evaluation terms off this site.
  4. You investigate locally. Run the pilot package on recordings you are permitted to analyze.

What RIA does not do

  • It does not automatically determine a verified physical root cause.
  • It is not a safety controller, a certified diagnostic system or a certification of robot health.
  • It does not provide continuous fleet monitoring through this website.
  • It does not offer public executable downloads, live checkout or automatic trial activation.
  • Real-world physical-fault precision and recall have not been independently established.
