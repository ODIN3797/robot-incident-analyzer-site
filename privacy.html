Privacy & Data

Last updated: November 12, 2026. This notice describes this public early-access preview, not a customer data processing agreement.

Public website and example report

This is a static GitHub Pages website. The public incident explorer is a hand-authored fictional illustration, and the linked real-engine HTML report was generated using only built-in fictional inputs. This website does not ask you to upload any ROS bag, robot log, or dataset. We have not embedded analytics scripts, advertising trackers, third-party fonts, or a checkout form in this site.

Platform hosting and public GitHub issues

GitHub hosts the website and public request/feedback issue forms. GitHub may process account data, site requests and operational logs under its own policies. Opening an issue exposes its contents and your GitHub identity publicly. Do not put emails, employer/customer names, logs, credentials, serial numbers, system details or confidential files in any public issue.

Private trial

Approved trial binaries run locally. The public site has no telemetry collection endpoint, and no remote logging service is part of the website. Installation and trust decisions are yours: the Windows executable is unsigned and the analyzer does not sandbox untrusted recordings. Any separate commercial support, file transfer or paid service needs a separate private agreement and an appropriate data-handling arrangement.

Your choices

You can view the fictional report without a GitHub account. You need a GitHub account to submit a public issue. Do not upload logs or personal details. You may close your public issue or use GitHub's normal controls for your account, subject to GitHub's retention policies.

No independent real-world physical fault accuracy, safety certification, or production-service guarantee has been established.
