Our AI robot videos are fictional comedy. The sample report is genuine RIA engine output generated from fictional data — not a verified field diagnosis.

What RIA does

Go from scattered telemetry to evidence you can review.

ROS and robot telemetry inputs

Inspect supported ROS2 bag files and timestamped robot event/telemetry CSVs using an offline workflow.

Timeline and review findings

Compare observed events and signals, flag candidate anomalies, and jump to supporting timestamps.

Shareable reports

Generate HTML/JSON investigation outputs. Rules identify review candidates—not automatically verified root causes.

Want to evaluate RIA locally?

1 · Prepare your request in this browser

Prepare a request using four fixed choices: your role, operating environment, recording format, and investigation goal. You can create and copy a draft without an account. Nothing is submitted from the request builder.

Prepare my request

2 · Submit the public GitHub request

To actually request access, review and post your information through our public GitHub issue form. A GitHub account is required and your request, including your GitHub username, is public. Share only your general role, log format and what you want to investigate — never your email address, employer or customer names, credentials, or logs.

Continue to public GitHub request ↗

3 · Agree on private delivery

Requests are reviewed manually and approval is not guaranteed. If approved, arrange a private delivery channel separately. There is no immediate download or payment on this page; Windows portable EXE and Python options are described in the evaluation guide.
